# Community Audits — Public Ledger

This directory is the public ledger for non-classified audit results generated by the DETERMINISTIC_LOGIC_ENGINE_V1.0.

## Submission Instructions

1. Run `ai-safety/tools/log_generator.py` to generate a standardized JSON report.
2. Place the output file here following the naming convention:

```
audit_YYYY-MM-DD_<report_id_prefix>.json
```

3. Open a pull request with your audit file. No personal identifying information is required.

## Schema

Every file in this directory must conform to the DETERMINISTIC_LOGIC_ENGINE_V1.0 schema:

```json
{
  "report_id": "uuid",
  "session_date": "YYYY-MM-DD",
  "session_transparency_score": 0.0,
  "traiga_compliance_rating": "PASS/FAIL",
  "total_breach_events": 0,
  "categories_triggered": [],
  "hard_kill_events": 0,
  "obfuscation_confirmed": true,
  "breach_events": []
}
```

## Filing Path

Completed audit records may be submitted to the Texas Attorney General Consumer Protection Division:

https://www.texasattorneygeneral.gov/consumer-protection/file-consumer-complaint
